타일 마스터의 시련

NYPC 2024 · 본선

메이플스토리의 새로운 지역, "리버스 시티"에서는 마법 타일이 N×MN \times MN×M 크기의 격자판을 이루고 있다. 각 타일의 앞면에는 빛의 문양, 뒷면에는 어둠의 문양이 새겨져 있으며, 모든 타일은 초기 상태에서 빛의 문양이 위를 향하고 있다.

모험가 여러분은 두 가지 마법 스크롤을 사용하여 타일을 뒤집을 수 있다. 스크롤은 사용해도 사라지지 않으며, 한 스크롤을 여러번 사용할 수 있다.

  • 빛의 스크롤: SSS 가지 종류의 빛의 스크롤이 존재하며, iii 번째 빛의 스크롤을 사용하면 연속한 AiA_iAi​ 개의 행을 선택하여 해당 행에 놓인 모든 타일을 뒤집을 수 있다.
  • 어둠의 스크롤: TTT 가지 종류의 어둠의 스크롤이 존재하며, iii 번째 어둠의 스크롤을 사용하면 연속한 BiB_iBi​ 개의 열을 선택하여 해당 열에 놓인 모든 타일을 뒤집을 수 있다.

모험가 여러분이 스크롤을 적절히 사용하여 모든 타일이 빛의 문양이 위를 향하도록 만들 수 있는 타일의 초기 상태를 아름다운 패턴이라 정의한다.

지역의 수호자, 타일 마스터는 시간의 흐름에 따라 타일의 문양을 조작하며 모험가에게 시련을 부여한다. 시각 000에는 모든 타일이 빛의 문양이 위를 향하고 있다. 111 이상 QQQ 이하인 iii에 대해 시각 iii가 되면 타일 마스터는 sxisx_isxi​, syisy_isyi​, exiex_iexi​, eyiey_ieyi​를 선택하고, sxi≤x≤exisx_i \le x \le ex_isxi​≤x≤exi​와 syi≤y≤eyisy_i \le y \le ey_isyi​≤y≤eyi​를 만족하는 모든 정수 xxx, yyy에 대해 xxx행 yyy열에 위치한 타일을 모두 뒤집는다.

이제, 모험가 여러분은 각 시각 iii에 대해, 해당 시각의 타일 상태를 시작 상태로 할 때 스크롤을 적절히 사용하여 모든 타일이 빛의 문양이 위를 향하게 만들 수 있는지, 즉 타일 상태가 아름다운 패턴인지 판별하는 프로그램을 작성하라.

입력 형식

첫 줄에 격자판의 크기를 나타내는 두 정수 NNN과 MMM이 공백으로 구분되어 주어진다. (1≤N,M≤300 000;1 \le N, M \le 300\,000;1≤N,M≤300000; N×M≤1 000 000N \times M \le 1\,000\,000N×M≤1000000)

그다음 줄에 빛의 스크롤 종류의 수를 나타내는 정수 SSS가 주어진다. (1≤S≤N1 \le S \le N1≤S≤N)

그다음 줄에 각 빛의 스크롤 특성값을 나타내는 SSS 개의 서로 다른 정수 A1,A2,⋯ ,ASA_1, A_2, \cdots, A_SA1​,A2​,⋯,AS​가 공백으로 구분되어 주어진다. (1≤Ai≤N1 \le A_i \le N1≤Ai​≤N)

그다음 줄에 어둠의 스크롤 종류의 수를 나타내는 정수 TTT가 주어진다. (1≤T≤M1 \le T \le M1≤T≤M)

그다음 줄에 각 어둠의 스크롤 특성값을 나타내는 TTT 개의 서로 다른 정수 B1,B2,⋯ ,BTB_1, B_2, \cdots, B_TB1​,B2​,⋯,BT​가 공백으로 구분되어 주어진다. (1≤Bi≤M1 \le B_i \le M1≤Bi​≤M)

그다음 줄에 시간의 길이를 나타내는 정수 QQQ가 주어진다. (1≤Q≤300 0001 \le Q \le 300\,0001≤Q≤300000)

이어지는 QQQ 개의 줄의 iii 번째 줄에는 시각 iii에 타일 마스터가 타일의 문양을 조작하는 방법을 나타내는 네 정수 sxisx_isxi​, syisy_isyi​, exiex_iexi​, eyiey_ieyi​가 공백으로 구분되어 주어진다. (1≤sxi≤exi≤N;1 \le sx_i \le ex_i \le N;1≤sxi​≤exi​≤N; 1≤syi≤eyi≤M1 \le sy_i \le ey_i \le M1≤syi​≤eyi​≤M)

출력 형식

첫 줄에 정답을 나타내는 길이 QQQ의 문자열을 출력한다. 이 문자열은 Y와 N으로만 이루어져 있어야 한다. iii 번째 문자가 Y이면 시각 iii에 타일 상태가 아름다운 패턴인 것이고, N이면 그렇지 않은 것을 의미한다.

예제 설명

시각 111의 타일 상태는 첫 번째 빛의 스크롤으로 111, 222, 333, 444행을 뒤집어 모든 타일이 빛의 문양이 위로 향하도록 만들 수 있다.

시각 444의 타일 상태는 첫 번째 빛의 스크롤으로 111, 222, 333, 444행을 뒤집은 후, 첫 번째 어둠의 스크롤으로 333, 444, 555, 666, 777, 888열을 뒤집어 모든 타일이 빛의 문양이 위로 향하도록 만들 수 있다.

시각 222와 333의 타일 상태는 스크롤을 어떻게 사용해도 모든 타일이 빛의 문양이 위로 향하도록 만드는 것이 불가능하다.

해설

편의를 위해, 빛의 문양이 위를 향하는 타일을 000, 어둠의 문양이 위를 향하는 타일을 111로 표현하자. 아름다운 패턴은 스크롤을 사용하여 모든 타일을 000으로 만들 수 있는 격자판의 상태를 뜻한다.

NNN행 MMM열의 격자판에서 각 타일의 상태를 Wi,jW_{i,j}Wi,j​로 정의하자. 여기서 Wi,j=0W_{i,j} = 0Wi,j​=0이면 iii행 jjj열의 타일이 빛의 문양을 위로 향하고 있음을, Wi,j=1W_{i,j} = 1Wi,j​=1이면 어둠의 문양이 위로 향하고 있음을 나타낸다. 타일을 뒤집는 연산은 타일의 상태를 000과 111 사이에서 전환하는 것이므로, 모든 연산은  mod  2\bmod\,2mod2로 생각할 수 있다. 타일의 상태 변화를 추적하기 위해, 누적 합과 유사한 개념인 변환값 배열 wi,jw_{i,j}wi,j​를 정의하자: wi,j=Wi,j−Wi−1,j−Wi,j−1+Wi−1,j−1(mod2)w_{i,j} = W_{i,j} - W_{i-1,j} - W_{i,j-1} + W_{i-1,j-1} \pmod{2}wi,j​=Wi,j​−Wi−1,j​−Wi,j−1​+Wi−1,j−1​(mod2)

단, Wi,0W_{i,0}Wi,0​과 W0,jW_{0,j}W0,j​는 모두 000으로 간주한다. 이렇게 정의하면, Wi,jW_{i,j}Wi,j​는 다음과 같이 표현할 수 있다: Wi,j=∑1≤x≤i, 1≤y≤jwx,y(mod2)W_{i,j} = \sum_{1 \le x \le i,\ 1 \le y \le j} w_{x,y} \pmod{2}Wi,j​=∑1≤x≤i, 1≤y≤j​wx,y​(mod2)

타일 마스터가 [sx,ex]×[sy,ey][sx, ex] \times [sy, ey][sx,ex]×[sy,ey] 범위의 타일을 뒤집는 연산은 www 배열에서 다음과 같은 변화를 일으킨다:

wsx,sy←wsx,sy+1(mod2)wsx,ey+1←wsx,ey+1−1(mod2)wex+1,sy←wex+1,sy−1(mod2)wex+1,ey+1←wex+1,ey+1+1(mod2)\begin{align*} w_{sx, sy} &\leftarrow w_{sx, sy} + 1 \pmod{2} \\ w_{sx, ey+1} &\leftarrow w_{sx, ey+1} - 1 \pmod{2} \\ w_{ex+1, sy} &\leftarrow w_{ex+1, sy} - 1 \pmod{2} \\ w_{ex+1, ey+1} &\leftarrow w_{ex+1, ey+1} + 1 \pmod{2} \end{align*}wsx,sy​wsx,ey+1​wex+1,sy​wex+1,ey+1​​←wsx,sy​+1(mod2)←wsx,ey+1​−1(mod2)←wex+1,sy​−1(mod2)←wex+1,ey+1​+1(mod2)​

따라서, 모든 타일에 대한 wi,jw_{i,j}wi,j​ 값을 관리함으로써 타일의 상태 변화를 추적할 수 있다.

빛의 스크롤의 사용은 sy=1,ey=Msy = 1, ey = Msy=1,ey=M 인 경우로 생각할 수 있고, 어둠의 스크롤의 사용은 sx=1,ex=Nsx = 1, ex = Nsx=1,ex=N 인 경우로 볼 수 있다. 따라서, 스크롤을 사용하여 모든 타일을 000으로 만들기 위해서는 wi,jw_{i,j}wi,j​에 대해 다음이 성립해야 함을 의미한다:

  • 모든 1<i≤N1 < i \le N1<i≤N, 1<j≤M1 < j \le M1<j≤M에 대해 wi,j=0w_{i,j} = 0wi,j​=0이어야 한다.
  • wi,1w_{i,1}wi,1​과 w1,jw_{1,j}w1,j​는 스크롤을 통해 조작할 수 있으므로, 적절한 스크롤 사용으로 000으로 만들 수 있어야 한다.

타일 마스터가 타일의 문양을 조작할 때마다 바뀌는 wi,jw_{i,j}wi,j​값이 444 개이므로, 이 값들은 계속 들고 있을 수 있다. 1<i≤N,1<j≤M1 < i \le N, 1 < j \le M1<i≤N,1<j≤M 인 i,ji,ji,j에 대해 wi,j=0w_{i,j} = 0wi,j​=0을 만족할 때, wi,1w_{i,1}wi,1​과 w1,jw_{1,j}w1,j​들의 값으로부터 아름다운 패턴인지 효율적으로 판단할 수 있으면 문제를 해결하는 데에 충분하다.

iii 번째 빛의 스크롤을 사용하면 1≤s≤N+1−Ai1 \le s \le N+1-A_i1≤s≤N+1−Ai​을 만족하는 sss 를 하나 골라 ws,1w_{s,1}ws,1​과 ws+Ai,1w_{s+A_i,1}ws+Ai​,1​에 1을 더하는 연산을 할 수 있다. jjj번째 어둠의 스크롤을 사용하면 1≤t≤M+1−Bj1 \le t \le M+1-B_j1≤t≤M+1−Bj​을 만족하는 ttt 를 하나 골라 w1,tw_{1,t}w1,t​과 w1,t+Bjw_{1,t+B_j}w1,t+Bj​​에 1을 더하는 연산을 할 수 있다. 이를 통해 wi,1w_{i,1}wi,1​과 w1,jw_{1,j}w1,j​들을 모두 000으로 만들 수 있는지 확인하면 충분하다.

빛의 스크롤로 모든 wi,1w_{i,1}wi,1​들을 000으로 만들 수 있는지, 그리고 어둠의 스크롤로 모든 w1,jw_{1,j}w1,j​들을 000으로 만들 수 있는지 확인하면 충분하다. 빛의 스크롤로 모든 wi,1w_{i,1}wi,1​들을 000으로 만들 수 있는지를 확인하는 방법은 다음과 같다.

111번부터 N+1N+1N+1번 까지 정점이 있고, 1≤i≤S1 \le i \le S1≤i≤S 에 대해 번호가 AiA_iAi​ 만큼 차이나는 모든 정점 쌍을 간선으로 연결한 그래프를 생각해 보자. 그래프의 iii번 정점에 있는 값을 wi,1w_{i,1}wi,1​라고 할 때, 간선의 양 끝점의 값을 반전시키는 연산으로 모든 값을 000으로 만들 수 있으면 된다. 그리고 이는 각 컴포넌트에서 wi,1w_{i,1}wi,1​의 합이 짝수인 것과 동치가 된다. 따라서, 그래프의 컴포넌트를 알면 각 컴포넌트 별 wi,1w_{i,1}wi,1​의 값들의 합을 관리함으로써 문제를 해결할 수 있다.

따라서, 처음에 주어진 AiA_iAi​와 BiB_iBi​들을 바탕으로 그래프의 컴포넌트를 계산해 놓으면 타일 마스터가 타일의 문양을 조작할 때마다 wi,jw_{i,j}wi,j​들의 값의 변화를 관리하면서 그래프에서 모든 컴포넌트가 짝수 합을 가지는지까지 체크해주면 아름다운 패턴인지 아닌지를 판정할 수 있다.
